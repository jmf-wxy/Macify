# Mac 风格超轻量桌面美化套件 (v0.0.2)

专为 Windows 10 / 11 设计的超低内存、超低 CPU 占用的原生 Mac 风格桌面增强套件。采用纯 C++20 与 Direct2D 硬件加速，零外部重量级框架依赖。

---

## 🌟 核心特性与架构亮点

### 1. 底部 Dock 导航栏
* **Direct2D 原生硬件加速**：支持 60/120Hz 丝滑高斯钟形曲线悬停放大动画。
* **常驻基础图标**：默认精简集成启动台、资源管理器、回收站、系统设置。
* **拖拽应用与交互固定**：支持从启动台直接将应用拖拽并吸附固定到 Dock 栏，支持气泡提醒。
* **极致性能优化**：鼠标离开后完全暂停渲染定时器，静止待机 CPU 占用稳定为 **0.00%**，常驻内存仅约 **9~15 MB**。
* **原生任务栏与全屏避让**：支持全屏游戏/应用智能检测自动休眠，支持自动隐藏 Windows 原生任务栏。

### 2. 应用抽屉启动台 (Launchpad)
* **全局桌面与开始菜单索引**：自动扫描系统桌面快捷方式与开始菜单，去重并过滤无效项。
* **应用自定义添加**：支持通过顶部按钮直接从 Windows 资源管理器选择 `.exe` 或 `.lnk` 文件加入启动台，支持文件拖放添加。
* **图标删除与永久屏蔽**：
  * 支持鼠标悬停时图标右上角浮现 macOS 风格红色 `✕` 删除角标。
  * 支持右键菜单选择“从启动台删除此图标（不再在此显示）”。
  * 删除后将目标自动加入持久化黑名单，即使全盘重新扫描或程序重启也**永久不再出现**。
  * 在系统设置中提供“一键恢复全部已删除图标”防误删机制。
* **秒级拼音/英文即时搜索**：光标自动闪烁，支持即输即搜与键盘上下键回车直达启动。

### 3. 桌面毛玻璃小组件 (Widgets)
* **数字时钟组件**：优雅显示时、分、秒与公历日期/星期，支持 12/24 小时制切换。
* **磁盘容量监控仪表盘**：实时读取驱动器容量与使用率，采用长周期低开销轮询机制（10~30 分钟可调，告别频繁磁盘唤醒）。
* **自由位置与锁定**：支持按住 Alt 键任意拖拽挂件摆放，并可在设置中一键锁定禁止误触。

### 4. 系统偏好设置控制台 (Settings)
* **原生 macOS 风格偏好设置面板**：划分为常规与系统、底部 Dock 栏、应用启动台、桌面小组件、个性化主题与外观、配置与关于六大专区。
* **个性化色彩预设**：预置深邃黑、太空灰、冰晶玻璃、极光紫 4 种全局毛玻璃视觉预设，以及经典蓝、翡翠绿、紫罗兰、珊瑚红 4 种强调色。
* **圆角曲率精细调节**：支持从 12px 到 32px 实时平滑微调所有卡片与底座圆角。

---

## 🛡️ 数据持久化与更新保护机制 (升级不重置)

* **配置解耦保存**：运行时配置自动持久化在可执行程序同级的 `config.json` 中。
* **增量安全升级**：构建与更新脚本 `build.bat` 具备智能保护机制，更新程序本体时**自动检测并保留本机已修改的用户配置**（包含自定义固定图标、隐藏黑名单、小组件位置与主题个性化设定），不再因版本升级导致数据被冲掉重置。
* **版本演进规范**：项目自当前改版起正式采用累加版本号规范（`v0.0.1` ➔ `v0.0.2` ➔ `v0.0.3` ...），版本定义统一收敛于 `src/core/Version.h`。

## 🚀 编译与构建

### 方式 1：使用 MinGW (g++) 一键构建（推荐）
在项目根目录下双击运行 `build.bat` 或在终端运行：
```powershell
.\build.bat
```
编译成功后，将在 `bin/` 目录下生成绿色单文件可执行文件 `MacDesktopBeauty.exe`。

### 方式 2：使用 CMake 构建
```powershell
cmake -B build
cmake --build build --config Release
```

## 📁 项目目录结构

```text
├── build.bat                   # 一键编译脚本 (内置配置防覆盖保护)
├── CMakeLists.txt              # CMake 构建配置文件
├── config.json                 # 默认出厂配置模板
├── .gitignore                  # Git 忽略配置 (保护私有配置与临时产物)
├── README.md                   # 项目开发与使用说明
└── src/
    ├── main.cpp                # 程序入口与系统托盘管理
    ├── core/
    │   ├── Version.h           # 全局版本号统一定义
    │   ├── Backdrop.h          # 系统级深色模式与圆角支持
    │   ├── DragOverlay.h       # 拖拽悬浮图标指示器
    │   └── D2DContext.h/.cpp   # Direct2D / DirectWrite 渲染管道
    ├── dock/
    │   ├── DockItem.h          # Dock 图标项与异步提取
    │   └── DockWindow.h/.cpp   # Dock 悬浮窗、缩放算法与交互
    ├── drawer/
    │   ├── AppItem.h           # 启动台应用数据结构
    │   ├── AppScanner.h/.cpp   # 桌面与开始菜单应用检索
    │   └── DrawerWindow.h/.cpp # 启动台抽屉窗口与黑名单删除
    ├── widgets/
    │   ├── IWidget.h           # 小组件基础抽象接口
    │   ├── ClockWidget.h/.cpp  # 数字时钟挂件
    │   ├── DiskWidget.h/.cpp   # 磁盘容量监控挂件
    │   └── WidgetHostWindow.h/.cpp # 桌面挂件宿主透明窗口
    └── settings/
        ├── AppSettings.h       # 集中式配置序列化与反序列化
        └── SettingsWindow.h/.cpp # 偏好设置管理界面
```
